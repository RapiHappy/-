# ЕГЭ OS 🎓

**Персональная операционная система подготовки к ЕГЭ 2027**

ЕГЭ OS — это умное PWA-приложение, которое работает как личный наставник, тайм-менеджер и трекер подготовки. Оно разработано специально для старшеклассников, чтобы сделать подготовку к экзаменам эффективной, предсказуемой и без выгорания.

## Особенности 🚀
- **Полная автономность**: Работает офлайн (PWA + IndexedDB). Все данные хранятся на устройстве.
- **Умный Режим Фокуса**: Встроенный Pomodoro (25/50/90 мин) с блокировкой отвлекающих факторов.
- **Управление энергией мозга**: Адаптация плана в зависимости от усталости (от 1 до 5).
- **Продвинутая аналитика**: Heatmap активности, графики стрик и предсказание готовности.
- **Интервальное повторение**: Ошибки автоматически предлагаются к повторению через 1, 3, 7 и 14 дней.
- **Мобильный UX (One-hand UI)**: Премиальный дизайн в стиле iOS/Telegram, свайпы и нижняя навигация.

## Технологический Стек 💻
- **Next.js 15 (App Router)** + Static Export
- **React 19** + **TypeScript**
- **Tailwind CSS v4** + **shadcn/ui**
- **Zustand** (Глобальное состояние)
- **Dexie.js** (IndexedDB)
- **Recharts** (Аналитика)
- **next-pwa** (Service Worker & Manifest)
