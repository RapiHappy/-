# Развертывание (Деплой) ЕГЭ OS

Так как ЕГЭ OS — это полностью клиентское (Static) приложение, его идеальный хостинг — **GitHub Pages**.

## Инструкция по деплою на GitHub Pages

1. **Отправка кода в репозиторий**
   Убедитесь, что все изменения закоммичены и отправлены в ветку `main` или `master`.
   
   ```bash
   git add .
   git commit -m "feat: init EGE OS"
   git push origin main
   ```

2. **Настройка GitHub Pages в репозитории**
   - Перейдите в настройки репозитория на GitHub: `Settings` -> `Pages`.
   - В разделе **Source** выберите **GitHub Actions**.

3. **Автоматический Деплой**
   - В репозитории уже настроен файл `.github/workflows/deploy.yml`.
   - При каждом пуше в ветку `main` запускается GitHub Action.
   - Action самостоятельно соберёт проект (Static Export) и опубликует его на Pages.
   - Следить за процессом сборки можно во вкладке **Actions**.

4. **Базовый URL (basePath)**
   Если вы разворачиваете проект НЕ на кастомном домене (например, `https://username.github.io/reponame/`), вам нужно раскомментировать `basePath: '/reponame'` в файле `next.config.ts`.
   Если репозиторий называется `-`, то путь будет: `basePath: '/-'`.

## Проверка работы PWA
После успешного деплоя, откройте сайт на телефоне (Safari / Chrome).
- Нажмите "Поделиться" -> "На экран Домой" (iOS)
- Или примите автоматическое предложение "Установить приложение" (Android).
Приложение будет работать даже без интернета (офлайн).
